# Cómo correr el proyecto Angular - Maquetación Web
Sigue estos pasos para ejecutar la aplicación web en tu entorno local.

## 1. Ir a la carpeta del proyecto
Abre una terminal y navega hasta la ruta donde está el proyecto:
```bash
cd Maqutación Web
```

## 2. Instalar dependencias
Una vez dentro de la carpeta del proyecto, instala las dependencias necesarias con:
```bash
npm install
```

## 3. Ejecutar el servidor de desarrollo
Después de instalar las dependencias, inicia la aplicación con el siguiente comando:
```bash
ng serve
```
