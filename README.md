# Cómo correr el proyecto Angular - Maquetación Web
Sigue estos pasos para ejecutar la aplicación web en tu entorno local.

## 1. Ir a la carpeta del proyecto
Abre una terminal y navega hasta la ruta donde está el proyecto:
```bash
cd Maqutación Web
```

## 2. Instalar dependencias
Una vez dentro de la carpeta del proyecto, instala las dependencias necesarias con:
```bash
npm install
```

## 3. Ejecutar el servidor de desarrollo
Después de instalar las dependencias, inicia la aplicación con el siguiente comando:
```bash
ng serve
```

# Cómo correr el proyecto Android - maquetación móvil
Sigue estos pasos para ejecutar la aplicación móvil en tu entorno local.

## 1. Importar la carpeta en Android Studio
Importar la carpeta SmartAlarmsApp dentro de Android Studio. La carpeta la puede encontrar en la siguiente ruta `Maquetacion Movil/SmartAlarmsApp`

## 2. Ejecutar el emulador de Android
Utilizando el Android Device Manager, ejecute el emulador del dispositivo en el que desea probar la aplicación. (Debe haber instalado los dispositivos con anterioridad). Espere a que el emulador se encuentre corriendo completamente antes de continuar con los siguientes pasos.

## 3. Instalar dependencias
Desde el IDE Android Studio, una vez que la carpeta esté importada ejecutar un Build del proyecto utilizando Gradle. (Esto puede tomar un tiempo).

## 4. Ejecutar la aplicación aplicación
